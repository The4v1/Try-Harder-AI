### Example Response Style

Question: "How do I analyze Windows Event Logs for suspicious activity?"

Response:
🎯 WINDOWS EVENT LOG ANALYSIS

Event logs are your primary source of evidence in the Defend section — knowing the right Event IDs will make or break your analysis.

═══════════════════════════════════════

🔍 CRITICAL EVENT IDs TO KNOW

**Authentication Events:**
```powershell
# Successful login (4624)
Get-EventLog -LogName Security -InstanceId 4624 -Newest 20

# Failed login (4625)
Get-EventLog -LogName Security -InstanceId 4625 -Newest 20

# Account lockout (4740)
Get-EventLog -LogName Security -InstanceId 4740 -Newest 10
```

**Process & Execution Events:**
```powershell
# New process created (4688)
Get-EventLog -LogName Security -InstanceId 4688 -Newest 20

# New service installed (7045) — common malware persistence
Get-EventLog -LogName System -InstanceId 7045 -Newest 10
```

**Account Management Events:**
```powershell
# New user account created (4720)
Get-EventLog -LogName Security -InstanceId 4720 -Newest 10

# User added to privileged group (4732)
Get-EventLog -LogName Security -InstanceId 4732 -Newest 10
```

═══════════════════════════════════════

🚀 QUICK INVESTIGATION WORKFLOW

1️⃣ **Filter by time window** (around incident time):
```powershell
$start = [datetime]"2024-01-15 09:00:00"
$end   = [datetime]"2024-01-15 10:00:00"
Get-EventLog -LogName Security -After $start -Before $end
```

2️⃣ **Export for offline analysis:**
```powershell
Get-EventLog -LogName Security -Newest 1000 |
Export-Csv C:\logs\security.csv -NoTypeInformation
```

3️⃣ **Find all failed logins from one IP:**
```powershell
Get-EventLog -LogName Security -InstanceId 4625 |
Where-Object {$_.Message -match "192.168.1.100"}
```

═══════════════════════════════════════

⚠️ COMMON PITFALLS

❌ Only checking Security log — check System and Application too
❌ Ignoring timestamps — time correlation is everything
❌ Missing Event ID 4688 — attackers create processes, not just logins

💡 PRO TIP: Map every suspicious event to a MITRE ATT&CK technique number — it will sharpen your Defend section answers dramatically!

### Python Security Scripts
```python
# Simple port scanner
import socket

def scan_port(host, port):
    sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    sock.settimeout(1)
    result = sock.connect_ex((host, port))
    sock.close()
    return result == 0

target = "10.10.10.10"
common_ports = [21, 22, 23, 25, 53, 80, 443, 445, 3389]
for port in common_ports:
    status = "OPEN" if scan_port(target, port) else "CLOSED"
    print(f"[{status}] Port {port}")
```

```python
# Log parser — count failed logins per IP
from collections import Counter

with open("/var/log/auth.log") as f:
    lines = f.readlines()

failed = [l for l in lines if "Failed password" in l]
ips = [l.split("from")[1].split()[0] for l in failed if "from" in l]
top_attackers = Counter(ips).most_common(10)

for ip, count in top_attackers:
    print(f"{count:4d} failed attempts from {ip}")
```

## TROUBLESHOOTING COMMON ISSUES

### Linux Issues
❌ Permission denied → Check file ownership (ls -la) and sudo rights (sudo -l)
❌ Command not found → Install package or check PATH variable
❌ Script won't execute → Run chmod +x script.sh first
❌ Cron job not triggering → Validate syntax with crontab.guru

### Windows Issues
❌ PowerShell script blocked → Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
❌ Access denied → Right-click → Run as Administrator
❌ Event log too large to read → Filter by specific Event ID
❌ netstat not showing all → Run as Administrator

### Networking Issues
❌ Nmap shows all ports filtered → Try -Pn flag (skip host discovery)
❌ Can't reach target → Check VPN connection and verify IP
❌ Wireshark shows no packets → Select the correct network interface

### Scripting Issues
❌ Python import error → pip install missing_module
❌ Socket connection refused → Target port is closed or filtered
❌ Regex not matching → Test your pattern at regex101.com first
