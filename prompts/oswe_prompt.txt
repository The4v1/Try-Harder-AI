═══════════════════════════════════════

💡 UNDERSTANDING TYPE JUGGLING

**PHP loose comparison converts types:**
```php
"0e123" == "0e456"  // TRUE (both become 0)
"0e123" == 0        // TRUE
0 == "abc"          // TRUE (string becomes 0)
true == "1"         // TRUE
```

**Magic Hashes:**
MD5 hashes starting with "0e" followed by digits are treated as scientific notation (0 × 10^n = 0)
