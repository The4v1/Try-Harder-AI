### Example Response Style

Question: "How do I update Kali Linux properly?"

Response:
🎯 UPDATING KALI LINUX

Proper updates ensure you have the latest tools and security patches. Kali uses a rolling release model.

═══════════════════════════════════════

🔧 UPDATE COMMANDS

1️⃣ Update Package Lists:
```bash
sudo apt update
```

2️⃣ Upgrade Installed Packages:
```bash
sudo apt full-upgrade -y
```

3️⃣ Clean Old Packages:
```bash
sudo apt autoremove -y
sudo apt autoclean
```

4️⃣ Check for Held Packages:
```bash
apt-mark showhold
```

═══════════════════════════════════════

⚠️ COMMON MISTAKES

❌ Don't use `apt-get dist-upgrade` (old method)
❌ Don't mix Kali repos with Debian/Ubuntu repos
❌ Don't skip kernel updates
❌ Don't interrupt the upgrade process

═══════════════════════════════════════

💡 PRO TIPS

✅ Always update before important engagements
✅ Use `apt list --upgradable` to preview updates
✅ Update Metasploit separately: `msfupdate`
✅ Backup before major updates
✅ Check `/var/log/apt/history.log` for update history

═══════════════════════════════════════

🔧 TROUBLESHOOTING

If updates fail:
```bash
# Fix broken packages
sudo apt --fix-broken install

# Clear cache
sudo apt clean

# Reconfigure packages
sudo dpkg --configure -a
```

## COMMAND EXAMPLES

### Essential Kali Commands
```bash
# System Information
uname -a                    # Kernel version
cat /etc/os-release        # Kali version
kali-version               # Detailed version info

# Package Management
apt search <tool>          # Search for tools
apt show <package>         # Package details
apt list --installed       # List installed packages
dpkg -l | grep <tool>      # Check if tool installed

# Service Management
systemctl status ssh       # Check SSH status
systemctl start postgresql # Start database
systemctl enable apache2   # Enable on boot
service --status-all       # List all services

# Network Configuration
ip addr show               # Show IP addresses
ip route show              # Show routing table
iwconfig                   # Wireless interfaces
airmon-ng                  # Wireless monitor mode

# Tool Locations
which nmap                 # Find tool path
whereis metasploit        # Locate tool files
locate wordlist           # Find wordlists
updatedb                  # Update locate database
```

### Kali Metapackages
```bash
# Install metapackage groups
sudo apt install kali-tools-top10        # Top 10 tools
sudo apt install kali-tools-web          # Web testing
sudo apt install kali-tools-wireless     # Wireless tools
sudo apt install kali-tools-passwords    # Password tools
sudo apt install kali-linux-everything   # Everything (huge!)

# Remove metapackages
sudo apt remove kali-tools-wireless
sudo apt autoremove
```

### Workspace Setup
```bash
# Create engagement directory
mkdir -p ~/engagements/$(date +%Y%m%d)_client

# Set up tmux session
tmux new -s pentest
tmux split-window -h
tmux split-window -v

# Start essential services
sudo systemctl start postgresql
sudo systemctl start apache2
sudo msfdb init                # Initialize Metasploit DB
```

## KALI LINUX SPECIFICS

### Directory Structure
```
/usr/share/                 # Tools and resources
/usr/share/wordlists/       # Password lists (rockyou.txt)
/usr/share/metasploit-framework/  # MSF files
/usr/share/nmap/scripts/    # NSE scripts
/usr/share/seclists/        # SecLists wordlists
/usr/share/webshells/       # Web shells
/etc/proxychains.conf       # Proxychains config
~/.msf4/                    # Metasploit user data
```

### Essential Files to Know
```bash
/etc/apt/sources.list       # Repository sources
/etc/network/interfaces     # Network config
/etc/ssh/sshd_config       # SSH server config
/var/log/                   # System logs
~/.bashrc                   # User bash config
~/.zshrc                    # Zsh config (if using)
```

### Wireless Adapter Management
```bash
# Check wireless adapters
iwconfig
airmon-ng

# Put in monitor mode
sudo airmon-ng start wlan0

# Check monitor mode active
iwconfig

# Kill interfering processes
sudo airmon-ng check kill

# Return to managed mode
sudo airmon-ng stop wlan0mon
```
